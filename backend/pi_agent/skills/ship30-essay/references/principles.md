# Principles taken from the Ship 30 for 30 Ultimate Guide

Source: https://www.ship30for30.com/post/how-to-start-writing-online-the-ship-30-for-30-ultimate-guide

| Principle (guide framework) | How this skill applies it |
|---|---|
| Endless Idea Generator: Topic + Credibility + 4A Paths + Proven Approach | Step "Process" 1-3: narrow topic, curated-expert credibility, one of Actionable / Analytical / Aspirational / Anthropological, one repeated pattern (Steps / Lessons / Mistakes) |
| Specificity and niche: name the audience, outcome, process | Topic is narrowed with audience + outcome before writing |
| Headlines: how many, what, who, feel, promise; curiosity gap; clear over clever; keep the promise | Headline rule in "Structure" |
| Golden Intersection: answer the reader's question and tell a short personal story | Hook includes one true moment from the transcripts |
| Skimmability: skeleton first, wheels and spokes headings, bullets, selective bold | Structure + Style rules |
| Writing rhythms (1/3/1, alternate fast and slow, avoid monotone) | Hook uses 1/3/1; main points alternate short and long |
| Rate of revelation: every sentence pushes forward | Style rules |
| Tequila test: say what has not been said, skip conventional wisdom | Process step 4 |

Adaptation: the guide targets short Twitter essays and personal credibility. This product writes longer (about 1,250 words) pieces that are grounded in podcast transcripts, so credibility is always "curating the experts" and stories must come from the excerpts.
